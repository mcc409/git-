# git笔记
用于焦糖工作室
· git status：查看当前状态（看看哪些文件被修改了，哪些还没提交）。
· git add：把修改过的文件添加到暂存区（相当于把文件放进购物车）。
· git commit：把暂存区的文件提交到本地仓库，并生成一个版本记录（相当于结账存档，并且可以写备注）。
· git diff：查看文件具体修改了哪些内容。
git相当于软件，工具
github相当于操作界面
在github中选定文件夹git初始化后建立了一个git库，该文件由git掌控
可以通过VS code打开该文件，在VS code中新建文件夹后，则可进行编辑，数据会同步到github，当你编辑完后，可在github中上传至main
